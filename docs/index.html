Ein privates Notizbuch über Mitspieler

A private notebook about the people you play with

Die Gruppensuche bietet keinerlei Kontext über frühere Begegnungen. Dieses Addon merkt sich, wer dabei war — und lässt einen selbst dazuschreiben, was man sich merken will.

The group finder offers no context about people you have met before. This add-on remembers who was there — and lets you add what you want to remember.

Stand: Logbuch funktioniert, Oberfläche fehlt. Erfassen, notieren, mit Merkmalen versehen und bewerten funktioniert und ist getestet — 33 Logiktests, alle grün —, bisher aber nur über Slash-Befehle. Die anklickbare Oberfläche ist der nächste Schritt.

Status: Logbook works, UI missing. Recording, noting, tagging and rating work and are tested — 33 logic tests, all green — but so far only through slash commands. A clickable UI is the next step.

Aufbau

Structure

Mehrere eigenständige Addons in einem Repository. Jedes Modul trägt ## Dependencies: PugLog und lässt sich einzeln abwählen – wer es nicht braucht, hat seinen Quelltext nicht im Speicher.

Several standalone add-ons in one repository. Each module declares ## Dependencies: PugLog and can be disabled individually – what you do not need is not loaded.

PugLog/                     Kern  – Logbuch, Speicher, Fenster
PugLog_LFGHighlighter/      Modul – Hinweis im Gruppenfinder
PugLog_CommunityShare/      Modul – Teilen in fester Gruppe

Der Kern kennt kein Modul namentlich. Er ruft nur Haken auf; wer sich angemeldet hat, wird gefragt. Ein Modul, das seine Voraussetzung nicht findet oder in einem Haken wirft, wird stillgelegt – nicht der Kern.

The core knows no module by name. It only calls hooks. A module that fails its check, or throws inside a hook, is disabled – the core is not.

Was es tut

What it does

Erfasst wird am Ende

Recorded at the end

Bei abgeschlossenem Schlüsselstein, gewonnenem Bosskampf oder beim Auflösen der Gruppe. Wer beim Betreten erfasst, hält die fest, die gleich wieder gehen — und verpasst die, die nachrücken.

On a completed keystone, a won boss fight, or when the group breaks up. Recording on entry captures those who leave right away and misses those who join later.

Notiz, Merkmale, Bewertung

Note, tags, rating

Eine geleerte Notiz wird entfernt statt als Leertext behalten. Eine Bewertung außerhalb von 1–5 wird begrenzt, statt einen Wert zu speichern, den die Oberfläche nicht darstellen kann.

An emptied note is removed rather than kept as empty text. A rating outside 1–5 is clamped instead of storing a value the UI cannot render.

Eine Grenze, von Anfang an

A limit, from the start

Je Person höchstens 25 Begegnungen — die Gesamtzahl bleibt trotzdem richtig. Die gespeicherte Datei wird bei jedem Ausloggen vollständig geschrieben.

At most 25 encounters per person — the total count stays correct regardless. The saved file is rewritten in full on every logout.

Was es nicht kann

What it cannot do

Ehrlichkeit an dieser Stelle ist wichtiger als eine vollständig aussehende Funktionsliste.

Being honest here matters more than a feature list that looks complete.

  • Es bewertet niemanden von selbst. Ein Addon, das aus Kampfdaten „guter Spieler“ ableitet, misst in Wahrheit Ausrüstung und Tagesform. Wer bewertet, tut das selbst — dann weiß er auch, was er gemeint hat.
  • It never rates anyone automatically. An add-on deriving “good player” from combat data really measures gear and daily form. Whoever rates, rates themselves — and then knows what they meant.
  • Es sortiert keine Bewerber. Der Gruppenfinder ist geschützter Bereich. Das Modul zeigt einen Hinweis; entschieden wird vom Menschen.
  • It does not sort applicants. The group finder is protected. The module displays a hint; the decision stays with the person.
  • Freitext wird nie geteilt. Eine Notiz ist für einen selbst geschrieben, in einer Sprache, die nur für einen selbst gemeint war. Geteilt werden — wenn überhaupt — Merkmale und Bewertung.
  • Free text is never shared. A note is written for yourself, in wording meant only for yourself. What may be shared — if anything — are tags and a rating.
  • Es führt keine öffentliche Liste. Es gibt keinen Weg, aus diesem Addon heraus eine Sammlung von Namen ins Netz zu stellen — und den soll es auch nicht geben.
  • It keeps no public list. There is no way to publish a collection of names from this add-on — and there should not be one.
  • Umbenennungen kann es nicht nachvollziehen. Der Schlüssel ist Name-Realm; nach einem Transfer ist ein Eintrag verwaist. Nicht lösbar, nur aushaltbar.
  • It cannot follow renames. The key is name-realm; after a transfer an entry is orphaned. Not solvable, only bearable.

Entwickeln

Development

tools/junction.cmd    # verbindet alle Addon-Ordner mit dem AddOns-Verzeichnis
./tools/test.sh       # Syntax, .toc-Abgleich und Logiktests (baut sich Lua 5.1)

Die Tests laufen ohne WoW: Die Spielumgebung wird so weit nachgebaut, wie der Kern sie anfasst. Geprüft werden vor allem die Stellen, an denen ein Fehler erst Monate später auffällt: Bewertungsgrenzen, das Umschalten von Merkmalen und die Verdrängung alter Begegnungen.

Tests run without WoW: the game environment is stubbed out as far as the core touches it. The tests focus on places where a bug only surfaces months later: rating limits, tag toggling, and the eviction of old encounters.
